# 贝通网管客户端构建说明

## 目标

桌面客户端基于 Electron 封装现有 Vue 前端。客户端内置 `frontend/dist` 静态资源；运行时只连接已部署的前端入口，由前端入口转发到 BT/SY 后端。

客户端支持：

- Windows 和 macOS 桌面窗口。
- 首次启动配置前端入口地址。
- 托盘菜单：打开客户端、服务地址设置、退出。
- `0.2.0` 起支持关闭到托盘、窗口/主进程/本机代理自动恢复，以及 Windows 登录启动和计划任务看门狗。
- 本机代理 HTTP API 和 WebSocket，经前端入口访问 `/bt-api`、`/sy-api`、`/bt-ws`、`/sy-ws`。
- 从记录页打开 Admin 时，使用系统默认浏览器打开前端入口下的 `/bt-admin` 或 `/sy-admin`。

当前不包含自动更新、代码签名、公证、后端/数据库/Redis/agent 捆绑。

## 默认前端入口

首次启动会弹出服务地址设置。默认值如下：

| 系统 | 默认地址 |
| --- | --- |
| BT | `http://127.0.0.1:38173` |
| SY | `http://127.0.0.1:38173` |

如果现场使用 HTTPS，可填写对应地址，例如：

| 系统 | HTTPS 地址 |
| --- | --- |
| BT | `https://<主机IP>:38443` |
| SY | `https://<主机IP>:38443` |

地址填写到前端入口根路径即可，不需要手动追加 `/bt-api`、`/sy-api`、`/bt-ws` 或 `/sy-ws`。

## 开发运行

在前端目录安装依赖：

```bash
cd frontend
npm install
```

运行桌面客户端开发版本：

```bash
npm run desktop:dev
```

该命令会先执行 Vue 构建和 Electron 主进程编译，再启动 Electron。

## 构建命令

macOS 本机构建：

```bash
cd frontend
npm run desktop:build:mac
```

Windows 构建：

```bash
cd frontend
npm run desktop:build:win
```

通用构建：

```bash
cd frontend
npm run desktop:build
```

构建产物输出到：

```text
frontend/desktop-release/
```

macOS 产物包含 `dmg` 和 `zip`。Windows 产物包含 NSIS 安装包和 `zip`。

## 验证清单

发布前至少执行：

```bash
cd frontend
npm run test:unit
npm run build
npm run desktop:compile
```

桌面冒烟验证：

1. 首次启动显示服务地址设置。
2. 保存 BT/SY 地址后进入登录页。
3. 登录后设备监控、当前告警、记录查询、运维管理、系统设置、拓扑页面可访问。
4. WebSocket 页面能建立连接。
5. 记录页“打开后端界面”使用默认浏览器打开真实后端地址。
6. 托盘菜单可打开客户端、打开服务地址设置、退出客户端。
7. 关闭最后一个窗口后进程仍在运行，并可从托盘重新打开。
8. Windows 安装后，任务计划程序中存在 `BeiTongNmsClientWatchdog`，当前用户启动项中存在 `BeiTongNmsClient`。
9. 在任务管理器中结束客户端进程后，等待不超过约 1 分钟，客户端应自动恢复到托盘且不主动弹出窗口。
10. 卸载后，计划任务和当前用户启动项均被删除。
